people (`dev-1`, `dev-2`, `QA`, reviewer IDs), reference plan sections
(`Phase 1.A7`, `Plan §NNN`, `Track H`), reference acceptance criteria
(`AC15`, `AC24`), or narrate review history (`# Reviewer-2 follow-up`,

Rule of thumb when rewriting (vs deleting):
- If the comment ONLY narrates history / cites a section / tags a finding →
  delete it.

  race condition, ordering requirement) → keep the *why*, strip the
  attribution.

contradicts the top-of-file "Comment policy". Rewrite to match.
