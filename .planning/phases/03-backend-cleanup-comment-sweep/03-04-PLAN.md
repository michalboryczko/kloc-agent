# Plan 03-04: ISS-11 — ClientDisconnect 499 / 204 distinction

## Objective

The JSONL ingress currently returns `202 Accepted` for every `ClientDisconnect`,
regardless of whether any frames landed before the disconnect. Distinguish:
- HTTP 499 ("client closed request", nginx convention) when no frames were
  dispatched before the disconnect.
- HTTP 204 (No Content) when at least one frame was dispatched before the
  disconnect — we accepted partial work.
