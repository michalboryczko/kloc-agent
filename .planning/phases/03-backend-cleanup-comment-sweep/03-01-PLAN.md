# Plan 03-01: ISS-08 — Gate `_diag` writes behind `Settings.diag_events`

## Objective

Add `Settings.diag_events: bool = Field(default=False, ...)` and route the
per-frame stderr diagnostic emitters in `src/api/internal.py` and
`src/api/webhooks.py` through that field. Default off so production traffic
does not pay a sync-stderr write per AG-UI event.

Note: `src/api/stream.py` has no `_diag` helper today, so the "align stream.py"
ask is a no-op there. Documented in SUMMARY.
