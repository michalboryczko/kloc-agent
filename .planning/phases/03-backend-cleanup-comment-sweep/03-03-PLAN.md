# Plan 03-03: ISS-10 — TTL cache on `RegistryEntry.is_alive`

## Objective

Add a small TTL result cache (~50 ms) so repeated `is_alive` calls during a
single hot loop don't fan out to the Docker daemon. Implementation lives on
`RegistryEntry`; the `Runner` Protocol stays clean.

## Tasks

<task id="1" type="auto">
  <behavior>Second `is_alive` call within 50 ms of the first returns the cached value without round-tripping the runner.</behavior>
  <implementation>
    - Add private fields on `RegistryEntry`: `_is_alive_cache: tuple[bool, float] | None`.
    - Add `async def is_alive(self, runner) -> bool` method that consults
      the cache (uses `time.monotonic()`) and only calls `runner.is_alive(self.handle)`
      on miss.
    - Update the two `await self._runner.is_alive(entry.handle)` sites in
      `RunnerRegistry.get_or_spawn` to call `entry.is_alive(self._runner)` instead.
  </implementation>
