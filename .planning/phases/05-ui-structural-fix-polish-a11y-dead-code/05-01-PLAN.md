# Phase 5 Plan 01: Structural fix — SessionRail + inline CopilotChat

## Objective

Replace the floating `<CopilotSidebar>` with an inline `<CopilotChat>` that
fills the right column of a 2-column CSS Grid. The left column hosts a new
`SessionRail` housing the SESSION card, RUNNER STATE pill, and ARTIFACTS list
(moved out of `AgentBody`). This is the canonical fix for finding F-1 — the
"75% black space" complaint.

- `frontend/src/components/AgentBody.tsx` — currently owns artifact wiring.

- `frontend/src/app/globals.css` — token theme + CopilotKit overrides.
- `docs/reviews/ui-design-review/design-direction.md` — rail spec (280px, 880px collapse).
- `docs/reviews/ui-design-review/findings.md#F-1` — canonical pain.
