# Phase 5 Plan 03: Accessibility audit (A-1 .. A-5)

## Objective

Sweep five accessibility items catalogued in
`docs/reviews/frontend/accessibility.md` / `findings.md`:

- **A-1** CopilotChat's internal textarea has no accessible name.
- **A-2** No `opacity`-based muted text remains; use `--text-mute` / `--text-dim`.
- **A-3** Header back glyph needs `aria-label`.
- **A-4** Busy session rows need `aria-busy` + scoped `cursor: wait`.
- **A-5** Heading hierarchy: `<h1>` for picker brand, `<h2>` for chat-view subtitle.
