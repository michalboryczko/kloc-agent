Downstream consumers spread the message into the AG-UI envelope, so the type still needs to be open enough to round-trip unknown extra fields — but TypeScript's structural typing already allows that without an index signature, and any unexpected fields land in the spread automatically.

  </implementation>
  <verification>

  - `cd frontend && npm test` still passes — the validator and ensureMessageIds tests still hold.
  </verification>
