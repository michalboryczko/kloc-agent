# Phase 6 Plan 01: CopilotRuntime hoist + CopilotKit dynamic import + memoization

## Objective

Resolve FE-PERF (7 findings in `docs/reviews/frontend/performance.md`) and
FE-BUNDLE (4 findings in `docs/reviews/frontend/bundle-and-loading.md`). The
two highest-leverage items are:

1. **Hoist `CopilotRuntime`** out of the per-request POST handler in
   `frontend/src/app/api/copilotkit/route.ts`.
2. **Dynamic-import `CopilotKit` + `CopilotChat`** in `frontend/src/app/page.tsx`
   so the session-picker route does not ship the chat bundle.

Plus a memoization sweep across `SessionRail.tsx`, `SessionPicker.tsx`,
`page.tsx`, `AgentBody.tsx`, `ToolCallCard.tsx` for inline-object /
hook-dep stability where genuinely needed.

## Tasks

<task id="1" type="auto">
  <name>Hoist CopilotRuntime + HttpAgent + handleRequest to module scope (S-1, B-bundle)</name>
  <files>frontend/src/app/api/copilotkit/route.ts</files>
  <behavior>
  The route handler currently allocates `CopilotRuntime`, `HttpAgent`, and
  `handleRequest` on every POST. The only per-request value is `proxyUrl(req)`
  which is just `${origin}/api/agent-proxy`. Since the proxy is always
  same-origin, hoist a relative URL to module scope and reuse a single
  runtime instance across all requests.
  </behavior>
  <implementation>
  - Allocate `const agent = new HttpAgent({ url: "/api/agent-proxy" })` at module scope.
  - Allocate `const runtime = new CopilotRuntime({ agents: { [AGENT_NAME]: agent } as any })` at module scope.
  - Allocate `const { handleRequest } = copilotRuntimeNextJSAppRouterEndpoint({ runtime, serviceAdapter, endpoint: "/api/copilotkit" })` at module scope.
  - Replace `export const POST = async (req) => { ... ; return handleRequest(req); }` with `export const POST = (req: NextRequest) => handleRequest(req);`.
  - Keep the `// eslint-disable-next-line @typescript-eslint/no-explicit-any` on the cast (existing TODO note remains valid).
  - Drop the unused `proxyUrl()` helper.
  </implementation>
  <verification>
  - `cd frontend && npx tsc --noEmit` passes.
  - `cd frontend && npm run build` succeeds.
  - Diff confirms `new CopilotRuntime(...)`, `new HttpAgent(...)`, and `copilotRuntimeNextJSAppRouterEndpoint(...)` appear at module scope.
  </verification>
  <done-when>
  Runtime allocated once; POST handler is a one-line `handleRequest` forwarder.
  </done-when>
</task>
