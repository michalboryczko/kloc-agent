# Plan 04-01: UI-P1 — Styling stack install

## Objective

Install Tailwind v4 + shadcn/ui baseline; replace `frontend/src/app/globals.css`
with a token theme drawn from `docs/reviews/ui-design-review/design-direction.md`;
load Instrument Serif + Geist + JetBrains Mono via `next/font`; override
CopilotKit CSS variables so the chat panel inherits the new theme; add the
radial-gradient + grain atmosphere to `body`. App must still build and boot at
every commit.

## Context

- @docs/reviews/ui-design-review/design-direction.md — token system (color,
  type, spacing, radius, shadow, motion) — maps directly to `@theme`.
- @docs/reviews/ui-design-review/styling-architecture.md — Tailwind v4 rationale.
- @.planning/phases/04-ui-foundations-component-reskin/04-CONTEXT.md — locked
  design decisions.
- Existing `frontend/postcss.config.mjs` is an empty stub (no plugins). It must
  be rewritten for the Tailwind v4 PostCSS plugin.
- `frontend/src/app/layout.tsx` currently has `<html><body>{children}</body></html>`
  with no font wiring; the global CSS import order is `@copilotkit/react-ui` THEN
  `./globals.css` so the new tokens win the cascade.

    - `frontend/src/lib/utils.ts` exporting `cn(...inputs: ClassValue[])`

## Success Criteria

1. Tailwind v4 + shadcn helper deps installed in `frontend/package.json`.
2. `frontend/postcss.config.mjs` activates `@tailwindcss/postcss`.
3. `frontend/src/app/globals.css` is a Tailwind v4 + `@theme` token file with
   CopilotKit overrides and the radial-gradient + grain body atmosphere.
4. `frontend/src/app/layout.tsx` loads 3 Google fonts via `next/font` and
   applies them as CSS vars on `<body>`.
5. `frontend/src/lib/utils.ts` + `frontend/components.json` exist (shadcn
   bootstrap artefacts).
6. `frontend/src/components/ui/{button,input,textarea,card}.tsx` exist with
   token-theme styling.
7. `npm run build` succeeds; `npm run lint` is clean.
