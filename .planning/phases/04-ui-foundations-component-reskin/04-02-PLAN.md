# Plan 04-02: UI-P2 — Component reskin

## Objective

Reskin `ToolCallCard.tsx`, `AgentBody.tsx`, and the chat-view header in
`page.tsx` onto the editorial-terminal token theme. Extract `SessionPicker`
from `page.tsx` into `frontend/src/components/SessionPicker.tsx` and reskin
it too. After this plan: no inline `style={{}}` blocks remain in any of the
four files; `<CopilotSidebar>` is **untouched** (Phase 5 replaces it). App
still builds at every commit.

  layout (`§ Picker view`), tool card spec (`§ Component-level treatment`).
- @.planning/phases/04-ui-foundations-component-reskin/04-01-SUMMARY.md —
  baseline established (Tailwind v4 + tokens + shadcn cn helper).
- Existing inline styles (28 hits) are documented in the phase context;
  they all map cleanly onto Tailwind classes + token vars.
- Pre-existing project lint pipeline is broken (Next 16 removed `next lint`).
  Build is the only gate.
