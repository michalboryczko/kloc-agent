<objective>
ISS-12: remove the silent-degradation `stub` runner mode entirely. Per
D-09..D-12, `kloc_runner_mode` is deleted from `Settings` and `.env.example`;
`src/main.py` lifespan unconditionally constructs `DockerRunner` and lets any
construction failure (ImportError, daemon unreachable) fail boot loudly; tests
that previously set `KLOC_RUNNER_MODE=stub` migrate to either avoiding lifespan
entry or injecting a fake `Runner` via the existing
`RunnerRegistry.set_runner()` seam.

Purpose: the `stub` mode masked the missing `/var/run/docker.sock` bind-mount
bug in production and broke every session-stream path after first user message
(see `src/main.py:98-102` comment). Removing it forces misconfiguration to
surface at boot.

Output:
- `Settings` loses `kloc_runner_mode`.
- `src/main.py` lifespan collapses to a single DockerRunner path that re-raises
  on failure.
- `.env.example` and `docker-compose.yml` no longer reference
  `KLOC_RUNNER_MODE`.
- `tests/unit/test_cors.py` no longer sets `KLOC_RUNNER_MODE`; functions
  unchanged because it uses `TestClient` *without* entering the lifespan
  context (already documented in the file's docstring).
- Regression test added to `tests/unit/test_settings.py` asserting the field
  is gone.
</objective>
